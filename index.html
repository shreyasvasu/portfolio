Sell-or-Store

Uncertainty-aware decision support for farmers

After harvest, a farmer must decide: sell now, or store and sell later. Instead of one price, it forecasts a calibrated range and turns it into advice.

  • LightGBM quantile regression + conformal calibration across tomato, onion and potato in 5 Karnataka districts.
  • Sell / Store / Split / Not sure, based on storage cost, spoilage and risk appetite.
  • Backtest on 1,613 forecasts avoided the ₹1.29/kg loss of always storing.
  • Flask + React, English and Kannada, with offline Kannada voice.

AEGIS-α

Automated Emergency Ground Intelligence System

A field medic's tools fail the moment the network drops. AEGIS-α mixes vision AI, wearables and mesh networking so it keeps working offline.

  • Gemini 3.1 Flash-Lite spots wounds and overlays TCCC MARCH triage on an AR HUD.
  • ESP32-CAM + MAX30102 stream heart rate and SpO₂ hands-free.
  • MANET mesh failover: Wi-Fi → GSM → SMS when networks are jammed.
  • Moondream2 + Gemma 2 9B on-device, zero cloud.

GlowUp AI

AI skin analysis web app

Many people can't easily reach a dermatologist. GlowUp AI reads skin from a single photo and returns a personalised, actionable report.

  • Gemini 3.1 Flash vision scores acne, dryness and pigmentation by region.
  • Advice tailored to skin type and allergies, from an India-first product database.
  • Routes cases needing a doctor to nearby dermatologists via Google Maps.

FlexAPI / SmartAPI

Adaptive API orchestration

Apps break when a third-party API slows down or dies. FlexAPI picks the healthiest provider for every request and switches automatically.

  • Scores providers on latency, cost, reliability and SLA.
  • Monitor → ML → Planner → Executor closed control loop.
  • Cooldown + switch penalty stops flapping; tested on a fault-injected Flask testbed.
