Sell-or-Store

Uncertainty-aware decision support for farmers

After harvest, a farmer must decide: sell now, or store and sell later. I built a system that forecasts a calibrated price range, not a single number, and turns it into advice.

  • LightGBM quantile regression + conformalized quantile regression (CQR) for tomato, onion and potato across 5 Karnataka districts, 2 and 4 weeks ahead.
  • Sell / Store / Split / Not sure advice from the farmer's storage cost, spoilage rate and risk appetite.
  • Backtested on 1,613 forecasts: avoided the ₹1.29/kg loss of always storing. Failure cases reported honestly.
  • Flask API + React UI in English and Kannada, with offline Kannada voice output.

AEGIS-α

Automated Emergency Ground Intelligence System

A field medic's support systems fail the moment the network drops. AEGIS-α combines vision AI, wearable sensors and mesh networking so it keeps working when connectivity doesn't.

  • Gemini 3.1 Flash-Lite spots wounds in real time and overlays TCCC MARCH triage steps on an AR HUD.
  • ESP32-CAM + MAX30102 over I2C stream heart rate and SpO₂ hands-free.
  • MANET mesh with automatic failover (Wi-Fi → GSM → SMS) for alerts on jammed networks.
  • Moondream2 + Gemma 2 9B run on-device with zero cloud dependency.

GlowUp AI

AI skin analysis web app

Many people can't easily reach a dermatologist. GlowUp AI analyses skin from a single photo and gives a personalised, actionable report, built in a 24-hour sprint.

  • Gemini 3.1 Flash vision scores acne, dryness and pigmentation by skin region.
  • Reports tailored to skin type and allergies, with an India-first product database.
  • Routes cases needing a doctor to nearby dermatologists via Google Maps; 15-day re-scan to track progress.

FlexAPI / SmartAPI

Adaptive API orchestration

Apps that depend on third-party APIs break when a provider slows down, gets expensive or goes offline. FlexAPI picks the best provider per request and switches automatically.

  • Scores providers on latency, cost, reliability and SLA; routes each call to the best one.
  • Monitor → ML → Planner → Executor closed control loop with automatic failover.
  • Cooldown + switch penalty prevents flapping; benchmarked on a fault-injected Flask testbed against static and circuit-breaker baselines.
